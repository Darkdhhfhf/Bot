# Bot

Современный отправщик сообщений в Telegram и VK через официальные API.

## Возможности
- Отправка в несколько чатов Telegram/VK.
- Интервал между сообщениями (общий или отдельно для каждой платформы).
- Шаблоны `{date}`, `{time}`, `{datetime}`.
- Защита от повторов (если последний текст совпадает).
- Режим теста (без отправки).
- Графический интерфейс (GUI).

## Быстрый старт
1. Создать и активировать виртуальное окружение:
   - `python -m venv .venv`
   - `source .venv/bin/activate`
2. Установить зависимости:
   - `pip install -r requirements.txt`
3. Запустить GUI:
   - `python gui.py`

## Веб-приложение
1. Установить зависимости:
   - `pip install -r requirements.txt`
2. Запустить веб-приложение:
   - `python web_app.py`
3. Открыть в браузере:
   - `http://localhost:8000`

### Режим Client API (рассылка через аккаунт)
1. Получите API ID и API Hash на https://my.telegram.org
2. В веб-интерфейсе выберите режим "Client API"
3. Введите API ID, API Hash и номер телефона (с +)
4. Нажмите "Запросить код" - код придёт в Telegram
5. Введите код в появившемся окне
6. После успешной авторизации сессия сохраняется - повторно авторизовываться не нужно
7. Теперь можно отправлять сообщения во все чаты аккаунта

Если GUI не запускается на Linux, установите пакет `python3-tk`.

GUI сам сохранит настройки в `.env` и `config.json`.

## Токены
- Telegram Bot API: получить у BotFather, сохранить в поле `Bot token`.
- VK API: токен сообщества/приложения с правами `messages`.

## CLI (опционально)
- `python app.py --text "Привет"`
- `python app.py --text-file message.txt --interval 5`

## Windows: автономный запуск (консоль)
### Вариант 1: запуск из исходников
1. Установите Python 3.10+.
2. Дважды кликните `run_sender.bat`.
3. Отредактируйте `message.txt` и запустите снова.

### Вариант 2: портативный exe (один файл)
1. Установите Python 3.10+.
2. Запустите `build_windows.bat`.
3. Готовый файл: `dist\BotSender.exe`.

Пример запуска exe:
`dist\BotSender.exe --text-file message.txt`

## Примечания
- Используйте рассылку только в своих чатах/сообществах и с согласием участников.
- Если получаете ограничения, увеличьте интервал.
- Защита от повторов сравнивает с последним текстом, отправленным этим приложением.
